# 5 Study Tips That Actually Work for CSE Exams

After going through multiple semesters of CSE exams, here's what actually moves the needle from average to top marks.

<!--truncate-->

## 1. Understand the Mark Scheme First

Before studying a topic, check how it's been asked in past papers. If "HTML forms" is always a 5-mark broad question, you need 5 distinct points — not just a definition.

## 2. Practice Writing Answers Out Loud

Viva exams test your ability to articulate. After reading a note, close it and explain the concept out loud. If you stumble, that's your study gap.

## 3. Code Examples Fix Uncertainty

Whenever you're unsure about a concept, write a working code example from scratch. If you can't — you don't fully understand it yet.

## 4. Use Spaced Repetition

Don't cram. Review HTML today, CSS tomorrow, JavaScript the day after, then cycle back to HTML. Builds long-term retention better than marathon sessions.

## 5. Study the Common Mistakes

The Common Mistakes sections on every note aren't just warnings — they're a map of where marks disappear. Study what goes wrong as much as what's correct.
