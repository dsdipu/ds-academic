# Welcome to DS Academic 🎓

I built this site because I struggled with the same thing every CSE student struggles with: **understanding concepts deeply enough to write exam answers confidently**.

<!--truncate-->

## The Problem

Most study resources teach you *what* something is. Teachers grade you on *how well you can explain it*. That gap is what DS Academic bridges.

Every note on this site includes what I call the **"Common Mistakes" section** — the exact errors that lose exam marks. Because knowing what NOT to do is just as important as knowing what to do.

## What You'll Find Here

Every note follows the same structure:
- 📌 **Quick Summary** — understand the core in 30 seconds
- 📚 **Deep explanation** — real understanding, not memorisation
- ⚠️ **Common mistakes** — the exact errors that lose marks
- 📖 **Exam questions** — with model answers and mark schemes
- 🎤 **Viva questions** — what teachers ask out loud

## How to Use This Site

Start with the [Learning Roadmap](/roadmap) for a structured path, or jump straight to any topic from the [Notes section](/docs).

For exam season, read [How to Write Exam Answers](/docs/exam-prep/how-to-write-answers) first — it's the highest-ROI note on this site.

Good luck. You've got this. 🚀
