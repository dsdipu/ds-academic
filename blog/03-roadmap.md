# The 3-Month Web Dev Roadmap for CSE Students (2026)

Starting web development from scratch with an exam in 3 months? Here's the exact order I'd recommend.

<!--truncate-->

## Month 1: HTML + CSS Basics

**Week 1–2: HTML** — Start with [HTML Introduction](/docs/web-technologies/html/html-introduction). Don't skip the common mistakes section.

**Week 3–4: CSS Basics** — [CSS Selectors](/docs/web-technologies/css/css-selectors) first — specificity appears in almost every exam.

## Month 2: CSS Layouts + JavaScript Basics

**Week 1–2:** Flexbox and Grid — the foundation of all modern layouts.

**Week 3–4:** [JavaScript Variables](/docs/web-technologies/javascript/js-variables) — hoisting is always tested.

## Month 3: Advanced JS + Docker

**Week 1–2:** DOM, Events, and ES6+ features.

**Week 3–4:** [Docker Introduction](/docs/web-technologies/docker/docker-intro) — the Docker vs VM comparison appears in nearly every exam.

## Final Week: Exam Prep

Read [How to Write Exam Answers](/docs/exam-prep/how-to-write-answers) first, then review all Common Mistakes sections.
